# モンスターの生成ソース

新規モンスターは `monsters/<id>/` にモデル生成コード、材質、部位、必要な動作と品質条件をまとめます。既存の [GOBLIN BRUTE](../characters/goblin_brute/) と [SKELETON GUARD](../characters/skeleton_guard/) は元の配置とコマンドで再生成できます。

人型は既存リグを適用できるか確認します。四足・飛行・特殊形状は最初の制作時に方向数、支持点、輪郭、必要な状態・動作を決め、検証方法と再現手順を `research/` に記録します。これらの専用生成処理は今後の研究対象です。

検証済みの素材を `docs/assets/<id>/` に置き、台帳に `type: "monster"` と該当するサブ分類、実際に公開した状態・動作を登録します。ゲームへの所属は採用が決まった時点で追加します。[素材台帳の仕様](../docs/TECHNICAL_DESIGN.md#素材台帳とギャラリー)
