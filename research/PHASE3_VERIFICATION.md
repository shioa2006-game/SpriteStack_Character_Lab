# Phase 3 異なる体形への共通モーション転用

## モデルと転用範囲

BRAMは幅広の緑の上着、銅色のひげ、丸い兜と盾を持つドワーフ戦士。幾何形状を組み合わせて独立した材質ボクセルと部位マスクを作り、剣を右手、丸盾を左手に付けた。LARKと同じ表示倍率で、低い身長、短い手足、広い胴の輪郭を読み取れる。モデルのソース、NPZ、17部位の関節座標、装備位置、パレットはキャラクターディレクトリにある。[BRAMのモデルと設定](../experiments/bram/)

| 構えの測定（モデル単位） | LARK | BRAM |
| --- | ---: | ---: |
| 床から最高ボクセル上端まで | 32.00 | 24.50 |
| 右肩から肘、手までの合計長 | 7.34 | 5.82 |
| 右股関節から膝、足首までの合計長 | 7.36 | 5.67 |

Phase 2の共通エンジンで両キャラクターの2関節IK、部位別剛体変形、再スライス、8方向レンダリング、PNGベイクを実行した。BRAMのカメラ、セル寸法、足元アンカー、部位名はLARKと同じ契約を使用した。

- **歩行。** LARKのクリップを同じファイルから読み込む。歩幅1.9モデル単位、接地区間、遊脚の持ち上げ、6コマ・9 fpsをそのまま適用できた。
- **攻撃の初回試験。** LARKの絶対座標の右手目標を適用すると、7つの動作キーのうち5つで右手がリーチ上限に達し、最大5.57モデル単位の目標差が出た。
- **攻撃の調整。** LARKでIKを解いた右肩から右手へのベクトルに腕の有効リーチ比を掛け、BRAMの各コマの右肩を原点として右手目標に変換した。全キーに同じ規則を適用した。ルート・胴の動き、踏み出し、刃の向き、左手の目標、コマ順と時間はLARKのクリップから継承した。最終の右手目標差は最大約 2.36 × 10⁻¹⁰ モデル単位。BRAMの剣の構え軸はモデルに合わせた。[変換コード](../experiments/bram/retarget_attack.py)

## 見た目の評価

全8方向の時系列画像とギャラリーで歩行・攻撃を確認した。原寸では緑の胴、ひげ、外に張った丸盾が見分けやすく、LARKより低く幅広い立ち姿になった。

- **歩行。** S・Nと斜め方向では、短い足でも左右の交代が読める。W・Eでは脚が重なり、足の入れ替わりが控えめに見える。支持足はコマ境界で固定される。コマを保持したまま画面上だけでルートを連続移動させた場合の足滑りと、実ゲームでの停止・旋回は未確認。
- **攻撃。** S・SW・N・NEでは、振り上げから剣を下ろす流れを追える。主要3局面（斬撃、下降、振り切り）の可視剣身はSで23・20・17 px、Wで15・6・5 px、NWで15・8・7 px、Eで12・6・13 px。W・Eは刃が胴や頭の輪郭に重なりやすく、NWの後半は剣先の動きが中心に見える。8方向で装備の持ち手の一貫性を確認した。

見た目の評価は制作者による確認。プレイヤーによる魅力度、斬撃の読みやすさ、操作感の評価と、コマ間を補間した武器の連続衝突は未実施。[公開ギャラリー](https://shioa2006-game.github.io/SpriteStack_Character_Lab/)

## 共通化に残った課題

同じ骨格の2体で、モデル・部位・装備とモーションの入力を替えて全8方向を生成できた。攻撃の手の目標はモデル空間の絶対座標のため、腕の長さによる変換が設定の前処理として残った。肩からの相対位置と腕のリーチを用いた目標表現は今後の検証対象。さらに短い脚では歩幅と接地区間の調整も必要になり得る。

ウェイト変形は、短い手足の肘・膝や、幅広の胴と肩の継ぎ目を評価するところから始める。支持足と装備を固定する現行の基準を保ち、粗いボクセルでの小片・段差の変化を比較する。側面の剣の遮蔽は、関節の継ぎ目と分けて刃の軌道やカメラで評価する。
