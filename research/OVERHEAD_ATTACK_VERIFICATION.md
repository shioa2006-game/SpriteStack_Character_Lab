# 大きく振りかぶる剣撃の検証

## 参考画像から採った動き

ローカルの `8way.png` を開き、上から指定の方向順に対応させて5局面を比較した。全方向で右手が肩より上がり、剣先が髪の外側を通って上から前と下へ動く。振り抜きでは脚の間隔が開き、胴が低く前に傾く。正面では腕の伸びと前傾、側面では剣の上下と前後の位置が斬り下ろしを伝える。参考画像の絵柄と装備は使用せず、両キャラクターの剣・盾・造形を引き継いだ。

| 方向 | 参考画像で見えた手がかり |
| --- | --- |
| S | 正面から、剣が頭の横を上がり、前に出した手と刃が低くなる |
| SW | 振り上げから斜め前・下への刃の移動と、踏み込み時の体の開きが読める |
| W | 手と剣先が頭上から画面左の低い位置へ移り、前方への伸びが見える |
| NW | 背面斜めから、剣先が頭の外側の上に出て、低い位置では体に一部が重なる |
| N | 背面から剣が頭の右側へ上がる。振り抜きでは刃より胴と腕の向きが手がかりになる |
| NE | 背面斜めから、頭の外側を通る剣先と体のねじりが読める |
| E | 横から剣の高低差が大きく、前方への伸びと踏み込んだ脚が見える |
| SE | 顔の向きと前傾に沿って斜め下へ刃が出る。振り抜きで体が低くなる |

## 現行から変えたこと

旧版は振り上げの最高点が低く、主斬撃キーでも剣先が高いままだった。LARKの右肘は複数のキーで約169°まで伸び、元の右手目標に最大1.21モデル単位届かなかった。旧BRAMは右手を転用済みだが、盾腕の目標には最大2.02単位届かなかった。旧リグの踏み出しでは右足の位置が前後に変わり、足底は床面に沿っていた。

両体形に共通のキーを作り、右手の目標は回転後の肩と腕の長さから求めた。ルート移動と踏み幅は脚の長さで換算し、盾腕は曲げる余裕を保つ位置に制限した。剣の軸は各モデルの握りと剣先から求めた。攻撃中に右足の高さを指定できるよう、既存リグへ任意の `front_lift` キーを追加した。

| コマ | 局面 | 時間 |
| ---: | --- | ---: |
| 1 | 構え | 60 ms |
| 2–4 | 腰を引き、右手を後ろ・上へ上げて頂点で溜める | 80 / 105 / 125 ms |
| 5 | 右足を着き、胴を前へ返しながら切り込む | 40 ms |
| 6–7 | 剣を前・下へ振り抜き、姿勢を戻し始める | 75 / 85 ms |
| 8–9 | 右足を戻して構えへ復帰する | 115 / 115 ms |

合計800 ms。静止・歩行のセルとアンカーを引き継ぎ、攻撃は64×64・アンカー(32, 48)、方向順は S / SW / W / NW / N / NE / E / SE。制作途中にLARKの斬り始めで検出した頭との交差は、振りかぶりの手を外へ移して解消した。NWで剣身が隠れた試作は、斬撃と振り抜きの手および刃を外寄りに調整した。[共通キー](overhead/clip.json)

## 技術検証

| モデル単位での計測 | LARK | BRAM |
| --- | ---: | ---: |
| 剣先の最高点、改善前 → 改善後 | 30.76 → 33.37 | 22.96 → 25.39 |
| 頂点で剣先が頭の上端を超える高さ | 1.46 | 1.04 |
| 頂点から斬撃までの剣先の前進 | 18.58 | 16.52 |
| 斬撃から低い振り抜きまでの剣先の下降 | 15.17 | 11.92 |
| 斬撃の右足の踏み幅 | 3.15 | 2.43 |
| 剣と右手 / 盾と左手の最小接触面数 | 10 / 19 | 60 / 60 |

- 各キャラクターの8方向×9コマで、透過、セル内の余白、アンカー、構えへの復帰を確認した。静止8コマと歩行48コマは両キャラクターとも既存の出力とRGBA全ピクセル一致。標準CLIの旧攻撃でも、関節と材質・部位のボクセルが旧ベイクと一致した。LARKの既存のパッケージ・歩行・攻撃テストも通過した。
- Chromeで両キャラクターの新旧攻撃、静止、歩行を元PNGと照合した。初回読み込み、8方向、コマ時間、原寸〜4倍、速度変更、方向・倍率・速度を保った新旧切替を確認した。
- 1区間を12分割した計97姿勢ずつで、右手・左手と両足がIK目標に10⁻⁶モデル単位以内で届いた。剣と右手、盾と左手の変形は一致した。剣身の64点（LARK）と97点（BRAM）の元ボクセル中心を各姿勢で身体と盾に照合し、交差は検出されなかった。右肘の曲がる向きの変化は隣り合う補間サンプル間で5°未満。剣先は頂点から斬撃まで前進し、続く振り抜きまで下降した。
- 左足底は全キー、右足底は斬撃・振り抜き・落ち着きの各キーで床面z=0。右足は振り上げと戻しで浮く。大きく動く区間を補間して検証したが、出力PNGは9枚の離散姿勢。剣身の面全体の連続衝突や、ゲーム内で床が動くときの接地は未検証。

## 8方向の視認性

斬撃 / 振り抜きキーで、カメラから見える剣身材質の画素を数えた。

| 方向 | LARK 改善前 → 改善後 | BRAM 改善前 → 改善後 | 改善後の見え方 |
| --- | --- | --- | --- |
| S | 22 / 27 → 22 / 27 | 23 / 17 → 18 / 18 | 頭上から横、下へ移る刃と、低くなった胴が読める |
| SW | 26 / 26 → 27 / 23 | 18 / 14 → 19 / 17 | 頂点の刃は短く見える。斬り始めと踏み込みは明確 |
| W | 11 / 9 → 13 / 12 | 15 / 5 → 12 / 7 | 腕が顔と重なる向き。頭上から前下方への移動は追える |
| NW | 10 / 12 → 4 / 6 | 15 / 7 → 6 / 2 | 振り上げは読める。斬撃・振り抜きは剣先の動きが主で、特にBRAMでは弱い |
| N | 21 / 22 → 20 / 22 | 17 / 15 → 13 / 13 | 右腕の上下と、下へ戻る刃が見える。BRAMの刃はやや短い |
| NE | 23 / 22 → 22 / 23 | 17 / 18 → 16 / 18 | 体の外に刃が出て、横から下への動きが読める |
| E | 10 / 16 → 14 / 17 | 12 / 13 → 14 / 13 | 斬撃で前に出る刃と、その後の下降が横から明確 |
| SE | 14 / 22 → 12 / 21 | 13 / 18 → 10 / 14 | 踏み込みは見える。短縮で斬撃の刃が短く見える |

両キャラクターとも、頂点・斬撃・振り抜きの各キーで全8方向に剣身が残った。

## 見た目の評価と限界

制作AIが原寸のコマと拡大比較を確認した。人間の試遊評価は未実施。

| 評価項目 | 所見 |
| --- | --- |
| 振りかぶり | 両体形で頭上に剣先が現れる。BRAMも肘を曲げたまま溜めが成立した |
| 斬り下ろしの力感 | 長い踏み込みと胴の前傾の後に低い剣先が残り、正面と側面で姿勢の差が明確になった |
| 一目で読めるか | S・SW・Eでは読みやすい。NWは短い剣先と胴の動きに頼り、SEは斬撃の刃が短い |
| 8方向の一貫性 | 1本の3D軌道を8方向へ投影した。右剣・左盾と、振り上げ・着地・復帰の順序は共通 |
| 参考画像との比較 | 高い溜め、前へ出る踏み込み、低い振り抜きに近づいた。背面斜めの剣の明瞭さには差が残る |
| 連続再生 | 800 msで構えに戻る。9コマでは頂点から斬撃に移る間隔が大きく、低速再生では段を感じる |
| ゲームでの気持ちよさ | 素材上は溜めと解放のメリハリを確認した。入力への応答やヒット感は実プレイで評価が必要 |

次の比較候補は、NWの剣を頭・胴の外に出せる肩と刃の組み合わせ、および800 msを維持したまま大きな振り下ろしの途中を読みやすくするコマ配分。比較は剛体リグで行った。[公開ギャラリー](https://shioa2006-game.github.io/SpriteStack_Character_Lab/)
