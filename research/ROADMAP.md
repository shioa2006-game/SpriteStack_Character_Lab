# 研究ロードマップ

現在の制作手順は [制作ガイド](CHARACTER_CREATION_GUIDE.md) にある。以下は開発順の記録で、初期研究のPhase番号と正式3体の仕上げPhase番号は別のもの。

## 実装・検証済み

- Sprite Stacking による LARK の人型立体モデルと32層の水平断面。
- 17部位を個別に剛体変換する関節リグと、腕・脚の2関節 IK。
- 歩行・攻撃モーションと、静止・歩行・攻撃それぞれの8方向レンダリング。
- 透過 PNG スプライトシート、セル寸法・方向順・アンカー・再生時間を含む JSON の出力。
- Windows での再生成とRGBA比較。Canvasギャラリーで静止・歩行・攻撃の全128コマを照合。[検証記録](PHASE1_VERIFICATION.md)
- Phase 2でモデル、部位、関節、装備、モーション設定を共通エンジンから分離。LARKの静止をモデルから描画し、歩行・攻撃と合わせて基準PNGと照合。[現在の回帰手順](../docs/TECHNICAL_DESIGN.md#研究用の回帰)
- Phase 3でBRAMの独立モデルに共通エンジンを適用し、歩行を共有、攻撃の右手目標を腕の長さに合わせて転用。両キャラクターをギャラリーに収録。[検証記録](PHASE3_VERIFICATION.md)
- Phase 4でBRAMの肩・肘・膝の局所ウェイトを試作し、同じポーズの剛体版と8方向で比較。接地と装備固定を照合。[検証記録](PHASE4_VERIFICATION.md)
- 画像からの生成実験01で、参考イラスト1枚から青髪の剣士MARENの立体モデルと静止8方向を生成。抽出・推測・未再現の特徴と、髪・外套の独立部位などのリグ拡張案を記録。[実験レポート](IMAGE_TO_CHARACTER_01.md)
- 画像からの生成実験02で、魔法使いCRYSTAL MAGEの長いローブ、広がるマント、水晶の杖、魔法書を立体化し、静止8方向を48×48と64×64で比較。剣・盾の取り付け枠に別の装備を入れられることを確認し、マント・裾を動かすための従属部位と描画順の課題を記録。[実験レポート](IMAGE_TO_CHARACTER_02.md)
- 実験01・02を比較し、共通の制作工程、繰り返した問題の設計規則、自動検証の項目、共通化の提案（当時）を整理。次の参考画像のための手順を文書化。[比較分析](IMAGE_TO_CHARACTER_COMPARISON.md) · [制作ガイド](CHARACTER_CREATION_GUIDE.md)
- 静止だけのベイク（`--modes idle`）と、設定ファイルで条件を変える汎用品質検証を共通化。[検証レポート](SHARED_IDLE_BAKE_AND_VALIDATION.md)
- 画像からの生成実験03で、共通化後の基盤だけを使い、スカーフで顔を隠した剣士AZURE RONINを制作。高い位置のポニーテール、平たいスカーフの端、2層の裾、反りのある片手剣を立体化し、装備1つ（16部位）の構成を確認。描画上の細い装備の途切れと、同じ材質の一部の可視画素は汎用検証の外にあることを記録。[実験レポート](IMAGE_TO_CHARACTER_03.md)
- MAREN・CRYSTAL MAGE・AZURE RONINの歩行8方向×6コマを、共通の歩行クリップと体格別の調整値で制作。布・髪の従属運動（裾は脚、房は胴の動きを遅れて追う）を共通機能 `walk.secondary` として実装し、汎用の歩行検証 `research.verify_walk` を追加。共通クリップの腕が同じ側の脚と一緒に前へ出ることを記録（LARK・BRAMは変更せず）。[歩行レポート](WALK_ANIMATION_VERIFICATION.md)
- 歩行時の頭部の連動を標準仕様 `walk.head` として共通リグに追加。頭は首に乗って胴の上下動を追い、移動は顔のボクセルが崩れない1.0単位刻み。3体で頭が全8方向・肩と一緒に1 px上下し、目の画素はコマで変わらない。検証に `walk.head.motion`・`walk.head.neck`・`walk.head.face` を追加。[頭部連動レポート](HEAD_MOTION_VERIFICATION.md)
- 武器を分離する設計を調査し、剣が途切れる主因を1画素1光線の取りこぼしと特定。[設計調査](WEAPON_SEPARATION_DESIGN.md)
- 分離はせず、MAREN・AZURE RONINの歩行の剣を `walk.fine`（剣の周りだけ1画素4×4本の光線、細い刀身の線の規則、剣の後ろに引く境界線）で描き直した。E方向の剣が1本につながり、暗い点線にならない。モデル、手首角度、他キャラクターの出力は不変。[剣の修正レポート](SWORD_WALK_VERIFICATION.md)
- 仕上げPhase 1で正式3体の攻撃を完成させ、Phase 2で共通歩行を独立させた。現行ギャラリーは3体を収録し、LARK・BRAMは研究側に保存している。[攻撃制作](SAMPLE_ATTACK_VERIFICATION.md) · [資産整理](SAMPLE_CLEANUP.md)

LARKとBRAMの標準生成は部位ごとの剛体変形を使う。ウェイト試作の評価範囲はBRAMの6関節。異なる骨格・装備配置への汎用転用は研究対象。LARK固有の歩行・攻撃の視認性と離散ポーズの制約は[元の技術検証](../experiments/lark_stage3/LARK_第3段階A_技術検証.md)に記録されている。

## 仕上げPhase 3で再確認した範囲

制作ガイドのコマンドを正式3体で試した。RONINの参考画像から抽出した20材質・比率と、3体のビルダーが作ったモデル配列は保存値と一致した。標準384コマと比較用静止16コマのRGBA、再生メタデータ、攻撃GIFは公開版と一致した。MAGEの詠唱比較GIFとポーズ表も再現できた。新しい参考画像での造形判断やゲーム内操作感は、この文書検証の対象外。[現行の制作手順](CHARACTER_CREATION_GUIDE.md)

## 今後の研究候補

1. **生成エンジンの高速化**。再スライス、描画、装備の可視計測、圧縮に分けて時間とメモリを計測し、変更の前後で LARK の RGBA を照合する。
2. **体形に依存しない攻撃目標の表現**。絶対座標の手の目標を、肩からの相対位置と腕のリーチに基づく表現で扱えるか検証する。
3. **モーション転用の適用範囲**。さらに短い脚や異なる足幅で、歩幅・接地区間・装備の配置をどう調整するか調べる。
4. **ウェイト変形による関節品質改善**。試作で接触の弱くなった肘を中心に、局所ウェイトと再サンプリングが輪郭、体積、小片に与える影響を調べる。
5. **複数装備への対応**。手への装着位置、解剖学的な左右、装備ごとの余白と遮蔽を検証する。
6. **キャラクターの自動生成と量産**。体形・配色・装備の設定を入力として、複数キャラクターのシートとメタデータを生成する方法を検討する。画像からの生成では、採色範囲と形状寸法の決定を自動化し、未経験の体形や衣装でも適切なセルと従属運動の設定を選べるか検証する。
7. **自動品質検証**。実装済みのRGBA、方向順、アンカー、透過、余白の回帰検査に加え、原寸での読みやすさを評価できる範囲を調べる。接地や斬撃の見え方は画像比較とプレイ評価で確認する。
8. **ゲームエンジンへの組み込み**。シートとアンカーを使い、停止・旋回・攻撃への遷移、当たり判定、操作感を実機で検証する。

今後はLARKとBRAMを回帰基準とし、関節の継ぎ目の形状と、接地・装備の剛体制約を個別に評価する。
