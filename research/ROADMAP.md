# 研究ロードマップ

## 実装・検証済み

- Sprite Stacking による LARK の人型立体モデルと32層の水平断面。
- 17部位を個別に剛体変換する関節リグと、腕・脚の2関節 IK。
- 歩行・攻撃モーションと、静止・歩行・攻撃それぞれの8方向レンダリング。
- 透過 PNG スプライトシート、セル寸法・方向順・アンカー・再生時間を含む JSON の出力。
- Windows での再生成とRGBA比較。Canvasギャラリーで静止・歩行・攻撃の全128コマを照合。[検証記録](PHASE1_VERIFICATION.md)

現行の LARK は、各ボクセルを一つの部位に割り当てて変形している。複数部位のウェイトを混合する変形と、別体形・別装備のキャラクターを同じエンジンで生成する仕組みは未実装。歩行・攻撃の視認性と離散ポーズの制約は[元の技術検証](../experiments/lark_stage3/LARK_第3段階A_技術検証.md)に記録されている。

## 今後の研究候補

1. **生成エンジンの高速化**。再スライス、描画、装備の可視計測、圧縮に分けて時間とメモリを計測し、変更の前後で LARK の RGBA を照合する。
2. **共通エンジンの整備とキャラクター設定のパラメータ化**。モデル、関節・部位、装備、モーション設定の入出力を整理し、LARK の既存シートを再生成できる境界を決める。
3. **異なる体形へのモーション転用**。関節長や足幅が異なる体形で、支持足の接地、剣・盾の取り付け、8方向のシルエットを比較する。
4. **ウェイト変形による関節品質改善**。肘・膝・肩のウェイト付けを試し、剛体方式に対する低解像度での利点と計算コストを測る。
5. **複数装備への対応**。手への装着位置、解剖学的な左右、装備ごとの余白と遮蔽を検証する。
6. **キャラクターの自動生成と量産**。体形・配色・装備の設定を入力として、複数キャラクターのシートとメタデータを生成する方法を検討する。
7. **自動品質検証**。RGBA、方向順、アンカー、透過とセルの収まりを回帰検査に組み込む。接地や斬撃の見え方は画像比較とプレイ評価で確認する。
8. **ゲームエンジンへの組み込み**。シートとアンカーを使い、停止・旋回・攻撃への遷移、当たり判定、操作感を実機で検証する。

Phase 2 では、LARK の PNG を回帰基準にして生成処理の計測を再現できるようにし、設定とエンジンの分離案を LARK 一体で検証する。異なる体形への転用は、その境界で LARK の同等出力を確認してから評価する。
