# MAREN　頭上からの踏み込み斬り

[原寸の新旧比較GIF](../docs/assets/maren/slash-comparison.gif) · [主要4方向のポーズ比較](../docs/assets/maren/slash-poses.png) · [攻撃GIF](../docs/assets/maren/attack.gif) · [透過スプライトシート](../docs/assets/maren/attack.png)

原寸GIFは各方向で左が初版、右が今回の斬撃。両方を同時に開始し、それぞれのコマ時間で再生する。静止比較はS・W・E・NWの3〜6コマ目を2倍に拡大した。基準は仕上げPhase 1のコミット `425e1ec` にあるMARENの公開シート。

## 参考画像から採った動き

参考画像の2ポーズ目では、手が顔の横に上がり、刃先が頭上に出る。続く2ポーズでは、前へ出した手と開いた足を残し、身体が沈むにつれて剣先が下がる。旧MARENは3・4コマ目で手も剣も同じ側に偏り、斬撃後は手を前に残していても剣先が手元に戻って見えた。今回は溜めのグリップを顔の横へ引き上げ、頭頂を越えた剣先が前へ走ってから足もと近くまで下がる軌道を描いた。

| 局面 | 配分 | 身体と剣の動き |
| --- | --- | --- |
| 構え・引き | 1–2コマ、60・70 ms | 静止姿勢から膝を曲げ、盾を体の前に寄せて剣を外へ引く |
| 振り上げ・最大の溜め | 3–4コマ、80・160 ms | 右足を浮かせ、剣を背後から頭頂へ運ぶ。胴を44°ひねった姿勢を一拍保つ |
| 斬撃 | 5コマ、50 ms | 右足を斜め前に着き、胴を−29°へ返す。剣先が頂点から33.1単位前へ出る |
| 深い振り抜き | 6コマ、140 ms | 右足を着地位置に残す。上体を20°前傾させ、腰を下げ、刃を前下方へ振り切る |
| 収め・復帰 | 7–9コマ、70・100・70 ms | 重心を戻し、右足を引き上げて静止と同じ構えに戻る |

| 指標（モデル単位） | 初版 | 今回 |
| --- | ---: | ---: |
| 最大の溜めでの右手の高さ | 25.08 | 27.21 |
| 剣先の高さ　溜め → 斬撃 → 振り抜き | 36.02 → 23.37 → 9.03 | 39.80 → 23.20 → 3.31 |
| 溜めから振り抜きまでの剣先の前進 | 12.64 | 31.53 |
| 着地した右足の移動　前方・外側 | 2.25・0 | 4.70・3.50 |
| 振り抜きでの腰の沈み | 0.64 | 2.40 |

同じ立体と両腕・両脚のIKから8方向を焼いた。踏み出し足の外側への移動だけを任意キー `front_outward` として追加した。値のないクリップでは移動量は0。斬撃の剣を再スライスする際に必要な余白として、MARENの姿勢ボリュームの前端を25から26へ広げた。カメラ、画素密度、72×72セル、足元アンカー(36, 52)、方向順、9コマ・800 msは初版と同じ。

## 原寸での再生と検証

Chromeで新旧比較GIFを原寸・通常速度で再生し、同じ方向のシルエットを見比べた。WとEでは、背後に引いた刃が頭上で止まり、前に伸びてから膝より低く落ちる。旧版で同じ場所に見えた3・4コマ目の違いが側面でも読める。NWでは試作の斬撃が髪に隠れたため、斬撃の刃を前へ送り、低い振り抜きに別の手首の向きを与えた。最終版では頭上・頭の横の前方・胴の外側の低い位置を順に通る。Sの斬撃は奥行き方向に短く見えるが、開いた右足と腰の沈み、続く低い剣先が踏み込みを伝える。

| 全身描画で見える刀身の画素数 | S | SW | W | NW | N | NE | E | SE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 溜め（4） | 33 | 26 | 18 | 24 | 22 | 21 | 23 | 35 |
| 斬撃（5） | 16 | 14 | 31 | 29 | 27 | 19 | 20 | 23 |
| 振り抜き（6） | 39 | 29 | 24 | 18 | 19 | 18 | 23 | 34 |

NEの振り抜きには、単独描画でも刀身が2片に分かれる試作があった。6コマ目の手首ロールを−35°から−31°に調整し、振り抜きの刀身が全8方向で1本につながることを確認した。

NWの復帰（8）では刃が胴の後ろに入り、一時的に見えなくなる。握りは手に固定され、次の構えで再び見える。評価したのは素材とブラウザー上の再生。入力、ヒットストップ、効果音を合わせた実ゲームでの打撃感は未評価。

- 72セルすべてに3 px以上の透明余白があり、開始・終了は静止とRGBA一致。8区間を各12分割した97姿勢で、両手・両足のIK、手と装備の変換、剣身のボクセル中心と人体・盾の交差を検査した。9コマで剣と揺れた髪・衣装の交差は検出されず、手との接触面は剣が最低27、盾が最低21。左の支持足は全コマで接地した。
- MARENの静止・歩行は元の公開PNGとデコード後RGBAが一致し、対応JSONも一致した。静止検証の既知の胸部断片は描画に現れない。共通リグの回帰としてLARK・BRAM・AZURE RONIN・CRYSTAL MAGEも別フォルダに焼き、各体の静止・歩行・攻撃の公開PNGまたは回帰基準と照合した。

## 再現

~~~powershell
$character = 'characters/maren/character.json'
$out = '.phase1/check-maren-slash'
python -m spritestack --character $character --out $out
python -m research.verify_attack --character $character --out $out --gif "$out/attack.gif" --published docs/assets/maren
python -m research.verify_walk --character $character --out $out
python -m spritestack --character $character --modes idle --out "$out-idle"
python -m research.verify_character --character $character --out "$out-idle"
python -m research.attack.outline --character $character --out $out
python -m research.maren_slash.compare --before research/maren_slash/baseline --after docs/assets/maren --out "$out-comparison"
~~~
