# オブジェクトの生成ソース

新規オブジェクトは `objects/<id>/` にモデル、材質、床面の基準、必要な状態と生成手順をまとめます。公開済みのオブジェクトは現在0件です。最初に木箱、宝箱、大岩、石柱を予定しています。

- 静止物は必要な方向数・床面アンカー・タイルに対する大きさ・輪郭を決めます。
- 状態を持つ物体は、閉じた状態と開いた状態などを個別に登録します。各状態に `neutral` を持つJSONと横一列の方向別PNGを用意します。
- 動く物体は支点・支持面とコマ時間を決め、回転中のはみ出し、転倒後の接地、状態を切り替えた際の位置を原寸で確かめます。開閉・回転・転倒のベイクと検証器は今後の制作工程で実装します。

出力は `docs/assets/<id>/`、制作・検証の記録は `research/` へ置きます。台帳に `type: "object"` と状態・動作の参照を登録すると、一覧と共通ビューアに表示されます。単一の静止状態だけでも登録できます。[公開形式と接地表示](../docs/TECHNICAL_DESIGN.md#素材台帳とギャラリー)
